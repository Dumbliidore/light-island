## 依赖管理（所有项目通用）

> 环境：WSL (Ubuntu) + Zed 编辑器 + Cargo。所有命令在 WSL 终端执行。

动手写代码前，先掌握几个必用的工具命令（后续每个项目都会用到）。

### 创建新项目

```bash
cargo new 项目名        # 创建二进制项目（bin）
cargo new 项目名 --lib  # 创建库项目（lib，供他人调用）
```

创建后会生成目录结构：

```
项目名/
├── Cargo.toml   ← 项目配置与依赖清单
└── src/
    └── main.rs  ← 二进制入口（bin）或 lib.rs（lib）
```

### 添加依赖：cargo add（推荐）

**不要手动编辑 Cargo.toml 写版本号**，用 `cargo add` 会自动查询并写入**最新版本**：

```bash
cargo add rand        # 自动添加 rand 的最新版本
cargo add reqwest     # 自动添加 reqwest 的最新版本
cargo add serde --features derive   # 带特性添加
cargo add serde serde_json          # 一次添加多个
```

### 查找 crate：cargo search

不确定要用哪个 crate，或想知道某个包的最新版本，用 `cargo search`：

```bash
cargo search rand          # 搜索 rand 并显示最新版本
# rand = "0.10.x"          ← 显示可用的最新版本号
cargo search http
cargo search 关键词
```

### 版本号规则

Cargo.toml 中的 `rand = "0.10"` 表示"兼容 0.10.x 的最新补丁版本"（语义化版本 SemVer）。`cargo update` 可升级到允许范围内的最新版。

> 💡 提示：文档中的版本号仅作示例。**请以 `cargo search` 查询到的实际最新版本为准**，用 `cargo add` 添加即可，不必手动改版本号。
